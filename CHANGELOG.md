# Changelog

All notable changes to the technical standards module are documented here.

The release tag is the consumer contract. Downstream BMad projects should pin an immutable tag such as `v0.1.0` rather than track `main`.

## [0.1.0-alpha.1] - 2026-09-03

### Added

- Release-management guidance for SemVer versioning, changelog maintenance, release-note drafting, snapshot validation, and confirmation-gated publication.
- A prerelease-management skill for alpha, beta, and release-candidate workflows.

### Status

- Internal pilot prerelease. `STD-LOG-001` and `STD-API-001` remain `draft` and advisory only.
